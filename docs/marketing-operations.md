# Website leads and campaign reporting

Apply migrations/001_marketing.sql to a private Cloudflare D1 database and bind the production Pages project to it as LEADS_DB. Restrict database access to the sales and operations staff responsible for enquiries. Agree retention and a daily inbox owner before activation. Review new website_enquiries in the private D1 console daily. The website exposes submission and availability only. WhatsApp and email remain available during outages. A confirmed submission means saved to the sales inbox, not email delivery. Review the website's published privacy notice before activating storage.

Use consistent utm_source, utm_medium and utm_campaign values on each campaign. With analytics permission the last explicitly tagged visit in the current browser tab supplies attribution. Untagged or unconsented enquiries go into the unknown bucket. Click-to-WhatsApp ads and offline leads require a separate CRM intake and matching process.

Ingest daily spend in MYR sen using an upsert keyed by reporting day (Malaysia), source, medium and campaign. Set qualified_at and quoted_at only from confirmed sales milestones. Import paid invoice totals in sen with an upsert on invoice_id, linked to the enquiry ID. Do not count deposits or quote values as full invoice payments. SELECT * FROM marketing_dashboard returns spend, leads, qualified leads, quoted leads, converted leads and collected revenue by acquisition cohort. Sum collected_rm / sum spend_rm for cohort ROAS where spend is positive. The private view includes spend-only campaigns and unknown attribution; it contains no contact details. Spend and post-enquiry milestones require account-side imports.

Direct GA4 owns page views and journey events. GTM must not send duplicate GA4 events or reinstall the Pixel or Clarity. Require explicit tag consent checks in GTM. Browser Meta measures PageView and Contact. Reserve Meta Lead for a confirmed CRM conversion with a stable CRM event ID; Purchase requires a stable transaction ID and actual paid value. Retries reuse the original ID and time. Confirm receipt with a temporary Meta test code before enabling CRM automations. Keep secret values in Cloudflare. Do not send raw form contents or contact details to analytics tags. Disable automatic GA4 form/outbound tracking or configure redaction if it includes mailto or WhatsApp draft content.
